01 / THE FIRST EXPERIMENT

A missing binding.
A provable counterexample.

The model has two base values. Its flawed rule uses loop_base without binding it to base. A researcher can choose values that satisfy the flawed rule while violating the intended rule.

The guest accepts that counterexample and produces a receipt. This tests the proof workflow; it does not reproduce the Orchard circuit.
